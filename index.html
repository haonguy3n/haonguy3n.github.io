Hi, I'm Hao Nguyen — an embedded software engineer. I work close to the hardware: firmware, device drivers, and the layers that turn a bare board into something people can actually use.

This site is where I keep notes on what I'm building and learning — debugging sessions worth remembering, tooling that saved me a week, and the occasional writeup of a project.

What I work on

  • Firmware — bare-metal and RTOS-based applications on microcontrollers.
  • Drivers & peripherals — I2C, SPI, UART, CAN, GPIO, timers, DMA.
  • C and C++ for production firmware, Python for tooling and test automation.
  • Debugging on real hardware — JTAG/SWD, logic analyzers, oscilloscopes.
  • Build & release — cross-compilation, CI for embedded targets, unit tests on host.
