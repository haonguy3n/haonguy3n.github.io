Hi, I'm Hao Nguyen — a senior embedded software engineer working on embedded Linux. I own the platform layer of connected devices: the Yocto build, the boot chain, Secure Boot and disk encryption, and the OTA pipeline that keeps a deployed fleet updatable without bricking it.

Over the past 4+ years I've shipped production firmware for security cameras, drones, and IoT devices on NVIDIA Jetson, Ambarella, and NXP i.MX. This site is where I write down what I learn along the way — the details that took days to find and that I don't want to find twice.

What I work on

  • Yocto / OpenEmbedded — BSPs, meta-layers, and custom distributions (meta-tegra, Ambarella SDK, NXP i.MX).
  • Platform security — Secure Boot (UEFI, signed UKI), full-disk encryption, dm-verity, read-only rootfs, secure elements.
  • OTA updates — A/B pipelines with Mender and SWUpdate, including rollback and upgrades of devices already in the field.
  • Languages — C, C++17/20, Python, Bash, Go.
  • Hardware — NVIDIA Jetson Orin, Ambarella, NXP i.MX6UL, SigmaStar, Raspberry Pi, BeagleBone.

Projects

  • orin-nx-camera-app — dual-sensor MIPI camera software for Jetson Orin NX: hardware H.265 streaming over an encrypted USB transport, on-device GPU face detection, and A/B OTA via SWUpdate.
  • se05x — provisioning CLI for the NXP SE05x secure element: on-chip key generation, CSR and certificate binding, exposed through PKCS#11.
  • osb — single-binary OS builder for bootable Alpine / Debian / Ubuntu images with signed UKI Secure Boot, dm-verity, A/B rollback, and reproducible builds.
